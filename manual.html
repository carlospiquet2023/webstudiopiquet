3. Alterar o WhatsApp

Coloque o número do seu cliente

📌 Passo a Passo:

  1. 1. Abra o arquivo HTML no VS Code
  2. 2. Pressione Ctrl + H (Substituir)
  3. 3. No campo "Localizar", cole: SEUWHATSAPP
  4. 4. No campo "Substituir", coloque o número do cliente (só números)
  5. 5. Clique em "Substituir Tudo"

❌ ANTES (encontrar isso):

https://wa.me/SEUWHATSAPP

✅ DEPOIS (substituir por):

https://wa.me/5511999999999

Atenção ao formato!

  • • Use apenas números, sem espaços ou traços
  • • Inclua o código do país: 55 (Brasil)
  • • Inclua o DDD: 11 (São Paulo), 21 (Rio), etc.
  • • Exemplo correto: 5521999999999
📸

4. Alterar o Instagram

Coloque o @ do seu cliente

📌 Passo a Passo:

  1. 1. Pressione Ctrl + H
  2. 2. Localize: https://instagram.com
  3. 3. Substitua por: https://instagram.com/nomedousuario

❌ ANTES:

href="https://instagram.com"

✅ DEPOIS:

href="https://instagram.com/salaobeleza"

Dica Extra

Você também pode adicionar links para Facebook, TikTok, YouTube, etc. Basta procurar os ícones de redes sociais no código e alterar os links!

5. Alterar Preços

Defina os valores dos serviços

📌 Passo a Passo:

  1. 1. Use Ctrl + F para buscar
  2. 2. Procure por "R$" para encontrar todos os preços
  3. 3. Altere cada valor conforme necessário

Exemplo de preço no código:

<span class="text-2xl font-bold">R$ 89,90</span>

🔍 Termos para buscar:

  • • R$ - Preços em geral
  • • partir de - Preços iniciais
  • • /mês - Mensalidades
  • • /único - Pagamento único

💡 Sugestões de preço:

  • • Site simples: R$ 299 - R$ 499
  • • Site + manutenção: R$ 499 + R$ 99/mês
  • • Serviços do cliente: pergunte a ele!
✏️

6. Alterar Textos

Personalize com os dados do cliente

📌 O que alterar:

  • ✏️ Nome do negócio: "Salão da Maria", "Barbearia do João", etc.
  • ✏️ Descrições: Textos sobre a empresa e serviços
  • ✏️ Endereço: Rua, número, bairro, cidade
  • ✏️ Horário: Dias e horários de funcionamento
  • ✏️ Serviços: Lista de serviços oferecidos

Exemplo - Título do site:

<title>Nome do Negócio - Slogan Aqui</title>

Exemplo - Texto de parágrafo:

<p>Somos especialistas em cortes masculinos desde 2010...</p>

Dica Profissional

Peça para o cliente enviar um texto pronto sobre a empresa dele. Assim você só precisa copiar e colar no lugar certo!

7. Alterar Cores

Combine com a marca do cliente

📌 Onde ficam as cores:

As cores principais ficam no início do arquivo, dentro da tag <script> do Tailwind:

Procure por "tailwind.config" no código:

tailwind.config = {
  theme: {
    extend: {
      colors: {
        primary: "#6366F1",   // Cor principal
        secondary: "#F8FAFC", // Cor de fundo
        accent: "#8B5CF6",    // Cor de destaque
      }
    }
  }
}

8. Alterar Imagens

Use fotos do negócio do cliente

📌 Como funciona:

As imagens nos sites usam links da internet (URLs). Você pode substituir por:

  • • Imagens do Unsplash (gratuitas)
  • • Fotos enviadas pelo cliente (hospedadas no Imgur)
  • • Imagens do Google Drive (com link público)

Exemplo de imagem no código:

<img src="https://images.unsplash.com/photo-xxx" alt="Descrição">

📤 Como usar o Imgur:

  1. 1. Acesse imgur.com/upload
  2. 2. Faça upload da imagem
  3. 3. Clique com botão direito na imagem
  4. 4. Copie o endereço da imagem
  5. 5. Cole no código HTML

🔍 Bancos de imagens grátis:

  • • Unsplash
  • • Pexels
  • • Pixabay
  • • Freepik

9. Publicar o Site

Coloque na internet gratuitamente

🎉 Boas notícias!

Você pode publicar sites gratuitamente usando o GitHub Pages. O cliente terá um link assim: nomedocliente.github.io

📌 Passo a Passo - GitHub Pages:

  1. 1 Crie uma conta no GitHub (ou use a do cliente)
  2. 2 Clique em "New repository" (novo repositório)
  3. 3 Nomeie como: nomedousuario.github.io
  4. 4 Faça upload dos arquivos HTML do site
  5. 5 Renomeie o arquivo principal para index.html
  6. ✓ Pronto! Acesse nomedousuario.github.io

Quer domínio próprio?

Se o cliente quiser um domínio como www.salaobeleza.com.br, você pode cobrar a mais pelo serviço. Registre em registro.br (~R$40/ano).
